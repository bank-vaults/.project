# Security Policy

## Reporting Security Issues

The Bank-Vaults maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/bank-vaults/bank-vaults/security/advisories/new) form.

For more details, see the [Bank-Vaults security policy](https://github.com/bank-vaults/bank-vaults/blob/main/SECURITY.md).
